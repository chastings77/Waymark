# Glossary

**Application opportunity**  
One row representing a specific hunt/application choice.

**Hunt ID**  
Stable, immutable identifier for an application opportunity.

**Queue**  
The ordered set of incomplete applications for an applicant and season.

**Skip for now**  
A session-only action that moves an item later without completing it.

**Not Applying**  
A persistent completion state indicating the user intentionally declined the opportunity.

**Applied**  
A persistent state indicating the external application was completed.

**Waymark Data**  
Proposed normalized Google Sheet used as Waymark’s operational data boundary.

**Master Hunt List**  
The existing V5 planning sheet containing the complete Texas opportunity catalog and strategy fields.

**Trailhead**  
The foundation milestone formerly described as Sprint 0.
