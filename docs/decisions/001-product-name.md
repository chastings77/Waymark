# ADR-001: Product name

- Status: Accepted
- Date: 2026-07-21

## Decision

The product is named **Waymark**.

## Context

The name must not restrict the product to Texas and should carry biblical and outdoor meaning without implying autonomous application submission.

## Rationale

Jeremiah 31:21 uses “waymarks” as markers used to retain and follow a path. The product helps the user maintain position through a complicated application journey.

## Consequences

- Repository name: `Waymark`
- Product language may use Trailhead, Waymark, Field Test, and Base Camp for milestones.
- Technical releases still use semantic versioning.
